# Phase 5 — 알림

> 핵심 MVP가 완료된 뒤 알림 저장·조회·읽음 처리부터 확장한다.

## Post-MVP 범위

- 알림 저장·목록·읽음 처리
- 알림 환경설정
- 검사 결과 알림

## 별도 검토 범위

- Web Push 구독 등록과 해제
- 서버 발송과 재시도
- 배치와 만료 정책
- 다중 서버 환경

현재 Service Worker의 알림 표시 코드는 서버 구독·발송 기능이 구현됐다는 의미가 아니다.

## 시작 조건

- Release 1 MVP 완료
- 알림 생성 시점과 수신 대상 정책 확정
- 개인정보·보존·재시도 정책 확정
