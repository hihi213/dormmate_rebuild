# Phase 4 — 최소 관리자

> 운영에 필요한 최소 조회와 합의된 상태 관리 기능을 제공한다.

## 확장 후보

- 사용자 목록
- 전체 물품 조회
- 검사 이력 조회
- 합의된 최소 상태 변경

## 시작 조건

[README의 1차 완료 기준](../../README.md#1차-완료-기준)을 충족한 뒤,
[이후 확장 원칙](../../README.md#이후-확장-원칙)에 따라 Task 범위를 정한다.

## 선행 결정

- `ADM-002`: 기능별 조회 범위
- 관리자 강제 삭제의 논리·물리 삭제 의미
- 역할 및 사용자 상태 변경 범위

현재 프론트의 mock 또는 fallback 결과를 백엔드 구현 근거로 사용하지 않는다.

## 완료 조건

- 모든 관리자 API에서 서버 권한 검증이 수행된다.
- 조회 범위와 변경 감사 필요성이 정책에 기록된다.
- 관리자 화면의 fallback 없이 실제 API 흐름을 검증한다.
